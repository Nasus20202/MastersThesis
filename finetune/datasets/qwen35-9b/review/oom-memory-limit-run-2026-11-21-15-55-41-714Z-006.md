## Summary

**Root Cause:** The application pods were being **OOMKilled (Exit Code 137)** because the memory limit was set to only **4Mi**, which is insufficient for nginx:1.31.5 to run stably. This caused continuous restart loops in CrashLoopBackOff.

**Fix Applied:** Updated the Deployment to increase both memory limits and requests from 4Mi to **64Mi**.
