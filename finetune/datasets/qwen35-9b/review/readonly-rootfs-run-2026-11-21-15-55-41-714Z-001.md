## Final report

## Summary

**Problem Identified**: The application rollout stopped because nginx containers with `readOnlyRootFilesystem: true` failed when trying to create required directories like `/var/cache/nginx/client_temp`. New pods crashed with "mkdir() failed (30: Read-only file system)", while older pods that started before the issue became apparent were still running.

**Solution Applied**: Added emptyDir volume mounts at paths nginx needs for runtime writes, keeping the root filesystem read-only:

- `/var/cache/nginx` - for nginx cache and temporary files
- `/var/run` - for nginx PID file and runtime data

**Changes Made**:

```yaml
# Added volumeMounts to container securityContext with readOnlyRootFilesystem: true
securityContext:
  readOnlyRootFilesystem: true
volumeMounts:
  - name: nginx-cache
    mountPath: /var/cache/nginx
  - name: nginx-run
    mountPath: /var/run

# Added emptyDir volumes
volumes:
  - name: nginx-cache
    emptyDir: {}
  - name: nginx-run
    emptyDir: {}
```
